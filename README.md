## 기술 스택

- HTML5, CSS3 (Grid, Flexbox, CSS 변수)
- Google Fonts: Pretendard, Fraunces
- Vanilla JS 없이 순수 마크업 + 스타일로 구성 (별도 프레임워크·빌드 도구 없음)
